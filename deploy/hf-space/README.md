# ETRM knowledge agent: demo backend

This Space runs the API for the multi-client ETRM knowledge agent, on synthetic data. The portal that uses it, and the full source, are here:

- Portal: https://icsmartbanana.github.io/etrm-knowledge-agent/
- Code: https://github.com/ICSmartBanana/etrm-knowledge-agent

Usage is limited: a shared daily question allowance, a per-visitor rate limit, and browser access only from the portal. The Space is deployed automatically from the GitHub repo, so don't edit it here.
